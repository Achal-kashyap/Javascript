## 💡 My Approach

> Don't just write code. Understand the logic behind it.

- Understand the problem first.
- Think of the logic before coding.
- Write a simple solution.
- Test different inputs and edge cases.
- Debug mistakes and improve the solution.

## 🔥 Developer Mindset

```javascript
while (learning) {
    practice();
    makeMistakes();
    debug();
    improve();
}
```
